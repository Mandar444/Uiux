# ClassBook — UI/UX Prototype

A premium, clickable mobile-app concept for a university classroom-booking system, built from the original Figma wireframes.

## View
Open `classbook-prototype.html` in any browser — no build step. It is a single self-contained file (HTML/CSS/JS).

## Features
- 13 fully designed screens: home/search, availability check, results, room details, booking form (with validation state), review, confirmation, my requests, request tracking (pending/approved), help & rules.
- Working flow, bottom-tab navigation, slide-out menu, light/dark theme, and an "All screens" picker.
- Fonts: Manrope + Plus Jakarta Sans + IBM Plex Mono.
